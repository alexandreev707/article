# Render: корректные креды к PostgreSQL

## 1. Самый надёжный способ — одна переменная

В **Web Service → Environment**:

1. Удали дубликаты, если есть: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` (чтобы не перебивали друг друга).
2. Добавь **ровно одну** строку подключения:

| Key | Value |
|-----|--------|
| `DATABASE_URL` | Нажми **копировать** у **External Database URL** на странице БД и вставь **целиком**, одной строкой. |

**Почему External, а не руками:** в URL уже правильные **логин**, **пароль** и **полный хост** (`…oregon-postgres.render.com`). Так не перепутаешь символы.

3. Оставь:
   - `SPRING_PROFILES_ACTIVE` = `prod`
4. По желанию (если снова будут обрывы):
   - `DB_SSL_MODE` = `disable` **или** `require` (попробуй оба при проблемах).

5. **Save** → **Manual Deploy**.

---

## 2. Не перепутать пароль (частая ошибка)

В пароле Render легко спутать:

- **`1`** (цифра) и **`l`** (латинская L)
- **`0`** (ноль) и **`O`** (буква)

**Не набирай пароль с экрана** — только **копирование** кнопкой у **Internal/External Database URL** или у поля Password.

На скрине у тебя в одном месте фигурирует `…dSNo1…`, в другом `…dSNol…` — это **разные** строки. Должна совпадать с тем, что **внутри скопированного URL** после первого `:` до `@`.

---

## 3. Если без DATABASE_URL (только отдельные поля)

| Переменная | Откуда |
|------------|--------|
| `DB_HOST` | Только **полный** хост из External URL, например `dpg-xxxxx.oregon-postgres.render.com` (**не** короткий `dpg-xxxxx-a` без домена). |
| `DB_PORT` | `5432` |
| `DB_NAME` | **Database** — у тебя `marketplace_r6b0` |
| `DB_USER` | **Username** — `marketplace` |
| `DB_PASSWORD` | Скопировать с вкладки Password / из URL |

---

## 4. Сеть (твой скрин Inbound IP)

Правило **`0.0.0.0/0`** = доступ откуда угодно — для БД с интернета это нормально для отладки. Для **Web Service → БД** в одном регионе трафик идёт по внутренней сети Render; IP rules на Postgres не мешают исходящим подключениям **из** твоего сервиса.

---

## 5. Минимальный набор env для запуска

```
SPRING_PROFILES_ACTIVE=prod
DATABASE_URL=<вставить External Database URL целиком>
```

После деплоя в логах не должно быть `UnknownHostException` и желательно нет `EOFException` при старте Flyway.
